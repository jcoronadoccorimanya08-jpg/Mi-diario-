# Mi Diario

Diario personal: a mano con tu lápiz (hoja con renglones), con teclado o por voz. Racha, calendario de ánimo, recuerdos de «hace un año», etiquetas, buscar y exportar a PDF.

- PWA offline, sin servidores ni analítica.
- Cifrado en el dispositivo (patrón y huella).

```bash
npm install
npm run check
```
